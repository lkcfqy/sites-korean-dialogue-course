## 最终落实的精确链接与词义修复

- 10个valid候选的完整词组按Word数组半开范围记录：保留自然空格、标点和助词，词头只在首词形锚定；linkedSpans仍保存所有组成词形及整组释义。点击范围内任一词形都能看整组意思，并分别听“这个词形”和“这个词组”。五个false候选继续排除。
- 单词形内的사월이네요和잘했어요分别还原사월/잘하다；不把跨空格的“사 월”泛化为月份，也不把普通잘副词冒充잘하다。
- “섞인 게 아닐까요”里的게为것+补语助词，不再解释成螃蟹；真实게/게가的动物义保留。
- 七种已核对的完整吃饭/服药句中，드세요改为드시다并限定为먹다的尊敬表达；真形容词드세다、提包들다和未审读形态不泛化。原“여기서 드세요?”有两处源位置，不重复计算为两个不同韩文句。
- “마음에 드시면 이걸로 드릴게요.”中的드시면限定为마음에 들다“中意”，与吃喝敬语드시다区分。
- “분리수거가 잘 안돼서 답답해요.”中的안돼서限定为안되다“不顺/未顺利进行”。国立国语院对“잘 안돼서”和事情不顺的用法说明支持此词形分析；结合本场后续垃圾分类不顺的上下文，项目作出这一精确语义判断。它是对本句的推断，不是官方审校了项目语料。参考[国立国语院：잘 안되다/잘 안 되다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=319737&searchCondition=&searchKeyword=)、[国立国语院：안되다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=316488&searchCondition=&searchKeyword=)。许可/禁止的안+되다不强合成这个词头。
