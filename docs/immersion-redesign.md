# 对话沉浸改造

日期：2026-10-09。以 Sites 第 13 版源码为起点。

## 当前用户目标

通过大量对话沉浸式学习韩语，循序渐进在半年内达到 TOPIK 6 对应的高级韩语能力。用户明确不以参加考试为目的，允许移除独立单词入口，并授权完成全部改进后发布。

本目标覆盖历史文档中的考试训练和 4,980 主线词全覆盖交付条件。词汇数据、语义审计与历史范围仍保留作为资料和质量检查，不再主导学习安排。

## 实现范围

- 首页直接进入对话，提供继续听、熟悉场景连听、薄弱句复习和阶段回顾；课程目录、每日安排、播放设置折叠。
- 移除导航和每日独立单词入口；旧 `/vocabulary` 链接回到对话。句中词义、形态、搭配与词典用例在原处展开。
- 六阶段 26 周递进路线，已有课程按原课日与稳定身份保留。重点学习以完整场景安排；时间不足或反馈需要帮助时减少场景数。高级阅读转为听读、讲述和真实用途的书面整理。
- 先听整段、理解查词、参与回应、换情境、连续泛听、阶段回顾六种学习方式。A/B 留白、循环、语速、连续范围和停止继续可用。
- 外部课程语音失败时显示错误并停止播放，可稍后重试。停止播放、请求超时与角色留白保留。
- 口头回应优先；麦克风录音最多五分钟，可回听或下载，离开练习清除。打字为可选笔记，不要求制造韩文文字才能记录口述或揭晓参考。
- 26 个独立每周变化情境，每个包含两种参考说法和一个追加条件；第 4/8/12/16/20/24/26 周七个独立阶段情境包含完整听力、理解问题、隐藏要点和开放口头任务。
- 真人听力资源使用官方视频和链接。四个 Easy Languages 视频仅按官方允许方式嵌入；TTMIK 长对话使用官方链接。没有下载或重新分发音频。
- 学习记录沿用既有浏览器存储与备份。新增听过场景、口述尝试、首次口述、参考曝光、追加条件和整段自评；这些与句子独立/延迟回忆、首次文字初稿保持分离。

## 保留范围与证据边界

原 26 周 182 课日、结课后实际发布日、原句 ID、韩中正文、原场景键、原迁移任务 ID 与词表顺序保留。已有 8,949 条原材料的审计不把新增练习刺激算成旧课程扩写。

参考揭晓前先保存曝光，保存失败时保留笔记并阻止换场；刷新、清空笔记、备份合并不重置参考与尝试历史。新增自评只记录学习者报告，不代表客观正确率或考试等级。阶段回顾在当前浏览器已有尝试或提示记录后按复练处理。

录音只在当前页面保留，不上传、不进入 JSON 备份。学习进度继续按网址保存在当前浏览器，未加入云同步。真人视频的实际访问取决于用户网络和发布方设置，始终保留官方来源链接；未把资源网页核对称为听觉审音或母语教师全量审校。

## 验证

- `npm run verify` 通过：格式、静态检查、类型检查、205 项自动测试、四项课程内容审计与生产构建全部成功。原课程数据与已有句子、场景、任务 ID 未改写。
- Chromium 实际浏览器验证通过 11 组流程：先听后看、原处查词、角色回应与切回双方播放、口述记录与录音回放、每周变化情境、阶段回顾、刷新后的首次尝试和参考历史、备份导入导出、熟悉场景连听与真人资源、旧链接跳转、各阶段与结课后课程加载。390×844 手机视口和 200% 文字缩放无水平溢出。
- 浏览器端对话音频流程使用确定性音频夹具验证；当时开发环境外部合成语音接口实测返回 502，不能据此宣称真实服务播放成功。2026-10-13 按用户要求移除设备备用语音，播放器回归测试验证失败时停止、保留服务错误且允许重试，以及取消播放、请求超时与角色留白。
- 真人视频核对了官方来源与嵌入许可，浏览器检查了按需嵌入和官方备用链接。未宣称逐条视频播放或听觉质量验证通过。
- 变更记录通过 `git diff --check`；发布包复用本次成功构建的产物。

## 2026-10-13 语音连接修复

旧 `speech.platform.bing.com/consumer/speech/synthesize/readaloud/edge/v1` 在 WebSocket 握手时返回 403；补齐请求头仍失败，上游时间与本地一致。词音列表仍包含 SunHi/InJoon，因此不是音色被移除。同期 [edge-tts 问题 #490](https://github.com/rany2/edge-tts/issues/490) 也报告旧连接失败与新版端点。

改用微软 `api.msedgeservices.com/tts/cognitiveservices/websocket/v1` 和 `Ocp-Apim-Subscription-Key` 参数，保留已实测可用的 GEC v1、原 SunHi/InJoon 音色、完整结束帧要求、取消、超时与缓存边界。请求头和消息时间戳与当前协议对齐。新端点直连实测握手 101，SunHi 返回 11,232 字节音频及 `turn.end`；这项验证证明合成返回音频，不等同于浏览器播放或听觉质量验证。后续错误日志显式记录错误名称与消息，不记录学习文本或上游带凭证 URL。

按用户要求删除设备备用语音模块和播放器调用；合成失败时直接停止并显示原服务错误，可手动重试，不换成设备音色。回归测试覆盖设备已有韩语声音时仍不调用设备合成、失败不推进队列和手动重试。
