# 对话补缺材料：首批 16 个场景

本批新增源材料是 `data/immersion/coverage-expansion.json`。它补写真实目的驱动的对话，覆盖初级日常、中级协调和高级理由澄清，共 16 个场景、60 个核心目标词。每场 10–12 条韩中逐句对应台词，均明确人物关系、目的和语体。本批是生成式编写及人工可复核的材料草稿，**没有完成独立母语者审校**；自然度、语义及难度还需持续复核，不称为已通过母语审校的完整词库。

## 选择依据和排程

依据 `data/dialogue-learning-audit.json` 的 `missingMainCourseWords` 选择目标，核对 `data/vocabulary.json` 的释义与 `data/immersion-word-schedule.json` 的首次排程。编写前更新后的审计仍确认这 60 词没有已链接的发布课程出现位置。无链接是机器证据缺口，并不自动证明原文没有该词；例如 `큰소리` 曾有拼写候选，本批明确使用“提高嗓门、大声说话”的语义。

每场均安排在所有核心词首次排程周之后，避免把尚未安排的核心词提前加入该场。新增场景是后来语境中的再遇见，不能用一次新增场景代替跨日独立回忆；编译后的复习安排仍需由课程系统执行。目标之外的辅助词没有全部按首次词表出现周机械限制，应按整个场景的可理解度进一步审查。

## 语体与难度审查

- 场景 1–3 使用具体物件、身份和当下动作；句子短，以 `이에요/예요`、`있어요`、常见请求和 `해요` 体为主。门店敬语根据角色使用。
- 场景 4–8 增加计划、询问许可、条件、原因和简短比较，仍以可见任务推动对话。
- 场景 9–11 包含分工、纠正误解和重新协商，避免只把信息问完就结束。
- 场景 12–16 保留多个理由、信息不足、不同利益和解决方案的局限，使用真实讨论中的较长回应。`만일` 等偏正式表达用于服务咨询；没有强制把所有对话写成论文腔。

## 编译与后续复核

编译器读取该 JSON 的 `lessonId/title/scene/kind/lines`，台词稳定 ID 采用 `${lessonId}-coverage-expansion-${场景数组序号}-${台词序号}`。这份数组应保持既有顺序，后续场景追加到末尾；不要重排旧场景或随意插删已有台词。编译器将新增文件放在现有补充材料之后，保护已有场景导航键。
